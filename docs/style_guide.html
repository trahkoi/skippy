Principles

Quiet surfaces, one accent

Do
  • Let the symbols carry the color. Hits are ink, skips are crimson.
  • Use crimson for actions and state: Share, the switch, 6-count, skip marks.
  • Show state by fading or filling, not by outlining.
  • Use hairline separators between regions.
Don't
  • Add borders or fills around slots and blocks.
  • Use more than one accent color.
  • Add a dark theme without redefining every token. The app is light only.
  • Rely on opacity alone to convey meaning without aria-current.

Notation

Six symbols per slot

Each two-beat block has six slots in the order & a 1 & a 2. A slot holds one of six states. Tapping steps through them in order and wraps. With Safe mode on, only states 0 to 2 are reachable.

SymbolMeaningState
Empty
Nothing played.		0
Light hit
Quiet note. Small filled dot.		1
Hit
Full note. Large filled dot.		2
Skip
A skipped count. Crimson slash.		3
Light ghost
Quiet ghost note. Small ring.		4
Ghost
Ghost note. Large ring.		5

Component

Focused block

Six borderless slots in two groups of three. The symbol sits over its label. Press state is a 0.96 scale. No fill or outline at rest.

Component

Block strip

One miniature per block, each with its symbols and its labels. The active block is full strength and the rest fade to 38%. Hover brings inactive blocks to 70%. Mark the active block with aria-current="true".

.strip { display:flex; gap:8px; margin-top:16px }
.thumb { flex:1; min-width:0; padding:12px 6px; border:1px solid transparent; border-radius:14px;
         background:var(--bg); display:flex; flex-direction:column; align-items:center; gap:8px;
         transition:opacity .18s }
.thumb .mini, .thumb .labs { display:grid; grid-template-columns:repeat(6,1fr); width:100% }
.thumb .mini svg { width:100%; max-width:20px; aspect-ratio:1; overflow:visible; justify-self:center }
.thumb .labs { font-size:11px; line-height:1; text-align:center; color:var(--muted) }
.thumb .labs b { font-weight:700; color:var(--ink) }

/* active state = everything else fades. No border, fill or underline. */
.thumb:not([aria-current="true"]) { opacity:.38 }
.thumb:not([aria-current="true"]):hover { opacity:.7 }

Accessibility

Notes for implementation

  • Slots are buttons. Give each an aria-label with its position and state, for example "Beat 1, hit".
  • Block strip uses role="tablist", tabs with aria-current / aria-selected, and labels like "Beats 3 to 4". Inactive opacity is visual only.
  • Switch is a button with role="switch" and aria-checked.
  • Contrast: ink 18.0:1, muted 5.2:1, crimson 7.6:1 on white. --line-strong is 1.7:1, so it is decoration. Controls must also be identifiable by shape, icon or label.
  • Focus: 2px crimson outline, 3px offset, via :focus-visible.
  • Motion: 120 to 180ms transitions on opacity, transform and background. All are disabled under prefers-reduced-motion.
  • Touch targets: slots are about 56px wide, buttons are 48px tall, icon buttons are 32px and should get extra hit padding on touch devices.
:focus-visible { outline:2px solid var(--brand); outline-offset:3px }
@media (prefers-reduced-motion: reduce) { * { transition:none !important } }
